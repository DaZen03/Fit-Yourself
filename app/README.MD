Fit_Yourself 

Aplicación móvil hecha en Android con Kotlin orientadad al registro, seguimiento, control de activiada fisica


-Características Principales

Autenticación de usuario: registro e inicio de sesión para usuarios con"Login Activity" y "Registro_Activity"
Gestión de Entreno: Registro de rutinas, ejercicios, pesos, repeticiones y duración de entrenamiento.
Base de Datos Local (Room): Almacenamiento local con distintas entidades.
Navegación Moderna: uso de Jetpack Navigation, y Menú inferior.

-Tecnologías utilizadas
Lenguaje: Kotlin
Ui: XML. material design 3, fragmentos
Arquitectura: Componentes (Room, lifecycle. Coroutines)
